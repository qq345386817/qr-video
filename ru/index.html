Скройте сообщение в видео, а затем раскройте его позже.

Secret Video Message — это приложение для личных видеосообщений для iPhone, iPad и Mac. Вы можете спрятать текст внутри видео, отправить видеосообщение, которое на первый взгляд выглядит обычным, и раскрыть скрытое сообщение позже, когда наступит подходящий момент.

Для чего это нужно?

Используйте его для личных заметок, внутренних шуток, подсказок, намеков на день рождения, паролей к событиям, пасхалок для создателей контента и небольших сюрпризов.
