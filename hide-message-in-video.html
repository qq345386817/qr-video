How to hide a message in a video

Secret Video Message turns a short note into a video that can be shared like a normal clip, then opened later to reveal the hidden text.

When this is useful

Hidden message videos work well for surprise notes, private clues, inside jokes, event hints, and small messages that should feel more personal than plain text.

Steps

  1. Open Secret Video Message on iPhone, iPad, or Mac.
  2. Choose Hide a Message.
  3. Type the note you want to hide inside the video.
  4. Pick a scene style or keep the default quiet note style.
  5. Generate the message video, then save or share the exported file.

Tips for better results

Keep the original exported video if the recipient needs to reveal the hidden text later. Some messaging and social apps may recompress videos, so the original file is the safest copy to keep.
