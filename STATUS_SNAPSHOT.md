# Website Status Snapshot

Updated: 2026-10-25

The independent `qr-video` repository contains the public Secret Video Message / 视频密信 website at https://qr-video.luopeike.com/.

The 2026-10-25 redesign aligns the website with the native App's current gray-blue brand and adds a documented design system, real localized App screenshots, shared navigation, responsive light/dark layouts, three-step product explanations, screenshot switching and native FAQ disclosures.

All 8 locales have equivalent homepage content. Existing help, support, privacy and English guide URLs are preserved: 35 canonical pages in total. The English documents no longer carry inactive duplicate Chinese sections. Arabic retains RTL layout. Canonical/hreflang tags and JSON-LD remain in the server-delivered HTML.

Use `README.md` for current source paths, build/check commands and publishing details. The previous May 2026 snapshot described the old layout, old colors and an incomplete locale set and has been superseded.

Release checks use the local metadata/link/contrast validator and Chromium at desktop and phone widths. Official design_check and design_system_check are unavailable in this environment; local checks are reported separately.
