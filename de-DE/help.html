Secret Video Message Hilfe

Was die App macht

Mit Secret Video Message können Sie eine Nachricht in einem Video verstecken, eine private Videonachricht senden und die versteckte Nachricht später enthüllen.

So verstecken Sie eine Nachricht in einem Video

1. Öffnen Sie „Nachricht verstecken“.

2. Geben Sie die Notiz ein, die Sie verstecken möchten.

3. Wählen Sie einen Szenenstil, wenn Sie möchten.

4. Tippen Sie auf die Schaltfläche, um die Videonachricht zu erstellen.

5. Speichern oder teilen Sie das exportierte Video.

So enthüllen Sie eine versteckte Nachricht

1. Öffnen Sie „Nachricht enthüllen“.

2. Wählen Sie eine Videonachricht aus Fotos oder Dateien aus.

3. Warten Sie einen Moment, während die App den versteckten Inhalt liest.

4. Anzeigen oder Kopieren des wiederhergestellten Textes.

So nutzen Sie die Share-Erweiterung

1. Öffnen Sie eine Videonachricht in einer anderen App, z. B. Fotos oder Dateien.

2. Tippen Sie auf die System-Schaltfläche „Teilen“.

3. Suchen und tippen Sie im Share-Sheet auf „Reveal Message“.

4. Der versteckte Text wird in der Erweiterung geöffnet und kann dort kopiert werden.

Fehlerbehebung für Secret Video Message

Die App kann mein Video nicht lesen.
Stellen Sie sicher, dass Sie ein mit Secret Video Message erstelltes Video ausgewählt haben, und versuchen Sie es dann erneut mit der originalen exportierten Datei.

Ich kann die Share-Erweiterung nicht finden.
Öffnen Sie das Share-Sheet, scrollen Sie durch die App-Liste und stellen Sie sicher, dass die Erweiterung auf Ihrem Gerät aktiviert ist.

Die wiederhergestellte Nachricht sieht unvollständig aus.
Versuchen Sie es erneut mit dem Originalvideo anstelle einer re-komprimierten Kopie von einem anderen Dienst oder einer anderen App.
