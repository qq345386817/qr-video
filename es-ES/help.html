Ayuda de Secret Video Message

Qué hace

Secret Video Message te permite ocultar un mensaje en un vídeo, enviar un mensaje de vídeo privado y revelar el mensaje oculto más tarde.

Cómo ocultar un mensaje en un vídeo

1. Abre Ocultar un mensaje.

2. Escribe la nota que quieres ocultar.

3. Elige un estilo de escena si lo deseas.

4. Pulsa el botón para generar el mensaje de vídeo.

5. Guarda o comparte el vídeo exportado.

Cómo revelar un mensaje oculto

1. Abre Revelar un mensaje.

2. Elige un mensaje de vídeo de Fotos o Archivos.

3. Espera un momento mientras la aplicación lee el contenido oculto.

4. Mira o copia el texto recuperado.

Cómo usar la extensión para compartir

1. Abre un mensaje de vídeo en otra aplicación, como Fotos o Archivos.

2. Pulsa el botón Compartir del sistema.

3. Busca y pulsa Reveal Message en la hoja de compartir.

4. El texto oculto se abrirá en la extensión y podrá copiarse allí.

Solución de problemas de Secret Video Message

La aplicación no puede leer mi vídeo.
Asegúrate de haber seleccionado un vídeo creado por Secret Video Message y vuelve a intentarlo con el archivo exportado original.

No encuentro la extensión para compartir.
Abre la hoja de compartir, desplázate por la lista de aplicaciones y asegúrate de que la extensión esté habilitada en tu dispositivo.

El mensaje recuperado parece incompleto.
Prueba de nuevo con el vídeo original en lugar de una copia comprimida de otro servicio o aplicación.
